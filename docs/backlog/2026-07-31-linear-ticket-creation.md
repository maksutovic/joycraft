# PRD → Linear ticket creation

Praful's end-state flow: interview → PRD (md + HTML, embedded in Notion) →
answers collected from teammates → then push the finished PRD into Linear as
tickets automatically, closing the loop from idea to assigned engineering work.

He explicitly framed it as optional for Joycraft ("you don't have to figure out
if this is worth it for you or I can just get a plugin later"). User-confirmed
at the 2026-07-31 gate that this is its own scope, beyond the team-ready-gates
revision. If picked up: likely a thin skill over the Linear MCP server rather
than anything in the CLI.
