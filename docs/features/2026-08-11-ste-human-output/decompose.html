Grounding

Repo facts this plan rests on

All four verified this pass by reading the tests and scripts directly — these are facts, not proposals.

Bundle parity is enforced

tests/bundled-files-sync.test.ts asserts src/bundled-files.ts matches src/templates/ byte-for-byte. Every spec that edits the template must run pnpm sync-skills and update docs/templates/reference/output-style.md in its own commit — no deferring sync to a terminal spec.

scripts/ never ships

package.json publishes only dist/. A vendored scripts/ste-lint.py cannot reach npm consumers, which is exactly the isolation D2 requires.

The rewrite owns its test

tests/output-style-template.test.ts reads only the canonical template. Amended D1 puts the test update inside the rewrite spec — new structure, retained score-scale and absolute-path bans. Rev 1's heading-collision constraint dissolved into this; zero invented constraints remain.

CI python is present but undeclared

CI runs pnpm test --run on ubuntu-latest, which ships python3, but no setup-python step declares it. The test skips with a legible message when python3 is absent, per design §2.4.
