payload/.joycraft/references/cleanup.md:82:
payload/.joycraft/references/cleanup.md:83:Decide the kind of each page first. The kind sets what "good" means.
payload/.joycraft/references/cleanup.md:84:

payload/.joycraft/references/cleanup.md:165:4. **Apply.** The agent that analyzed a part edits it: it knows the pages.
payload/.joycraft/references/cleanup.md:166:   Each agent edits only the files of its own part and writes every other
