Shape

What ships

Three inputs point the same way: Anthropic's Fable 5.1 prompting guide, Theo Browne's reset-to-defaults operator view, and the AI-native SDLC playbook's intent-to-incident chain. Joycraft already runs the middle of that chain. This feature closes the two ends and makes the Claude harness Fable-native.

Model profile doc

One reference doc carries the guide's tested prompt blocks by name. CLAUDE.md points at it in one Context Map row. Skills cite block names, never copy text. Installs for Claude, Pi, and omp; never Codex.

Intent inbox

docs/intent/ with a fixed shape: Author, Status, source, Problem, Proposed outcome, Affected users and systems, Constraints, Open questions. Interview writes one first. new-feature and bugfix consume by path. Triage is an interview mode.

Governance recipes

Four unregistered hook recipes in the Claude kit and an evals-in-CI scaffold under docs/templates/evals/. Nothing is written to .github/workflows/ by the installer. Every bugfix seeds an eval.

Optimize source

A model-profile evidence step flags legacy anti-formatting and hand-holding rules as RETIRE or PROBATION candidates. Advisory only. No auto-edits.

Boundaries

Constraints and scope

Must
  • One home per fact: Fable guidance lives in the profile doc; skills cite by name.
  • Gate the profile doc by harness. Reference docs install unconditionally today, so D6 is an installer change.
  • Intent source: field accepts human, interview, linear:<id>, alert:<name>, and future <system>:<id> without schema change.
  • Regenerate bundled variants and sync installed copies in the same commit as any skill edit.
  • Every spec adding a reference doc includes the dogfood update step; pnpm build alone does not reach docs/templates/.
Must not
  • Add runtime dependencies. Hooks and evals are shell, claude -p, and jq.
  • Write to .github/workflows/ during install or update.
  • Touch the holdout scenarios repo or its dispatch workflow.
  • Auto-edit a user's CLAUDE.md from optimize.
  • Add a Pi- or omp-scoped memory file; both read the root pair.
  • Ship REVIEW.md, the PR-review agent, the maintenance loop, Linear triggers, a triage skill, or an init-evals command. All backlogged or excluded.
Done

Success criteria

  • Fresh update with claude selected installs the profile doc and one Context Map row; codex-only installs neither.
  • update on an existing customized CLAUDE.md or AGENTS.md adds the row and changes nothing else; a second run is a no-op.
  • Pi-only and omp-only installs receive the profile doc.
  • docs/intent/ exists after install with a README and nothing else.
  • Interview with an empty inbox writes an intent before any brief; with two untriaged intents it offers triage first.
  • new-feature and bugfix given an intent path stamp intent: in frontmatter and leave the intent file in place.
  • Four hook recipes ship unregistered; the evals scaffold ships under docs/templates/evals/.
  • Optimize flags "never use markdown" as an advisory RETIRE candidate.
  • Joycraft's own repo shows all of the above after the dogfood spec, and its AGENTS.md carries no rule the model-profile step flags.
  • pnpm test and pnpm typecheck pass with no regressions in install, upgrade, or skill sync tests.
