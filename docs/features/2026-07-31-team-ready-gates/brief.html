Shape

What this revision does

Praful runs Joycraft as a team documentation engine across ~6 projects: draft PRD → HTML + md into Notion → teammates answer assigned questions → engineer pastes the agent prompt into Claude Code. Three things get in the way today; this revision removes them and hardens the public face.

Deterministic questions

Every gate question in Claude Code arrives through the AskUserQuestion picker, every time; codex/pi get decide's structured chat fallback. Plus the model/effort-question skip in tune/init fixed at the root (D1, D5).

Team answering

"Defer to <name>" is a first-class answer: the brief ends with an "Open Questions — Assigned" section and the HTML renders assignee-tagged cards ready to paste into Notion (D2).

Your template, your prompt

A user template in docs/templates/output/ shapes gate output, md + HTML; the brief/PRD gains a ready-to-paste "prompt for the implementing agent" slot (D3, D4).

Trackable artifacts, public trust

Every gate HTML shows a timestamp + revision banner and auto-open becomes a persisted setting (D6); README leads with install + TOC and a thin SECURITY.md lands (D7).

Boundaries

Constraints every spec respects

Must
  • pnpm sync-skills + regenerated copies committed in the same commit as any src/skills/ edit — 0.7.3 shipped twelve wrong copilot skills off a stale tree
  • Gate HTML skeletons stay byte-identical outside SLOT regions, even under custom output templates
  • Auto-open stays a no-op in headless/CI/isolated mode, never a failure
  • All template and skill paths stay project-relative
  • pnpm test && pnpm typecheck pass before every commit
Must not
  • No new runtime dependencies — template rendering stays agent-hand-filled, no md→HTML library
  • No model or tier recommendations — that is the backlogged model-tiering feature's scope
  • No freeform per-gate HTML — the locked-skeleton contract holds
  • No auto-writes to docs/backlog/ — every entry is user-confirmed
Done

Success criteria

  • Every gate question in Claude Code arrives through the AskUserQuestion picker; codex/pi get the structured chat fallback
  • Any question can be deferred to a named person; brief carries "Open Questions — Assigned" and HTML renders assignee-tagged cards
  • A user template in docs/templates/output/ shapes gate output; absent one, bundled defaults apply unchanged
  • Brief/PRD output includes the agent-handoff prompt slot
  • Every gate HTML shows a timestamp + revision banner; auto-open honors a persisted setting
  • init/tune reliably asks model/effort wherever it asks the swarm questions
  • README leads with what-it-is, install, TOC; SECURITY.md exists
  • pnpm test and pnpm typecheck pass; no regressions in existing gates
