D1 · SKILL SHAPE

Where does the deposition logic live?

Both joycraft-design and joycraft-new-feature end by producing an artifact a human must judge. The deposition step could be inlined into each, or become one shared skill both invoke. Skills must be self-contained (repo gotcha #3), but skill-to-skill routing is established practice (tune routes to assess/upgrade).

New shared joycraft-decide

Recommended
  • One canonical home for deposition logic — the optimize skill's own duplication-over-length rule
  • Design AND new-feature both route to it; future checkpoints reuse it
  • Pilot edits touch one skill, not two
  • One more skill in the routing vocabulary (discoverability tax)
  • Handoff must pass the design doc path cleanly
Blast radius
src/claude-skills/ +1 newdesign.md +5 linesnew-feature.md +5 linesdecompose.md gate checkbundle regen + installed sync

D2 · DOSSIER PERSISTENCE

Does the dossier file get committed?

The dossier is a generated human-only view (RF-DIET-1) — but views can still be worth keeping. The .gitattributes machinery from core-loop-refocus already exists for exactly this class of file.

Committed, marked linguist-generated

Recommended

  • Collapsed in PRs via existing .gitattributes machinery — zero review noise
  • Reaper-compatible: archives with its feature folder
  • Repo weight (self-contained HTML, tens of KB per feature)
