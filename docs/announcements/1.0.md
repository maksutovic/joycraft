# Joycraft 1.0 is out

Joycraft 1.0 helps your coding agent do larger work without losing track. You say what
you want. The agent writes it down, splits it into small steps, and builds each step
with tests. Then a second agent checks each step before it counts as done.

It works with Claude Code, Codex, Pi, Oh My Pi, GitHub Copilot CLI and OpenCode.

**New project.** Open your coding agent in the project and paste the
[install prompt](../prompts.md#install).

**Already on 0.7.** Paste the [upgrade prompt](../prompts.md#upgrade-from-07). The agent
shows you the plan first and changes nothing until you say go. If you change your mind,
`npx joycraft@latest rollback --yes` puts everything back.

**Staying on 0.7.** That is fine. Nothing changes until you choose. Use
`npx joycraft@0.7.17 update`.

**Tell us how it went.** This is why we are releasing now. Open a
[1.0 feedback issue](https://github.com/maksutovic/joycraft/issues/new?template=1-0-feedback.yml),
or paste the [feedback prompt](../prompts.md#send-feedback) and your agent drafts it
for you.
