Spec ship-governance-hook-recipes assumed exit 1 means "ask", that the generated `block-dangerous.sh` follows the contract, and that `src/bundled-files.ts` gets committed; in fact exit 1 is only a non-blocking warning (a real ask is exit 0 plus a JSON `permissionDecision`), `block-dangerous.sh` reads the tool name from `$1`, which Claude Code never passes, so as registered it always exits 0 and never blocks (and it prints its reason to stdout, not stderr), and `src/bundled-files.ts` is gitignored.
See `src/safeguard.ts` (`generateHookScript`), `src/templates/hooks/exit-code-gate.sh`, and `docs/features/2026-09-22-fable-native-sdlc-harness/specs/ship-governance-hook-recipes.md`.
